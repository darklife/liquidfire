# LiquidFire OS

Welcome to LiquidFire, a small operating system for 680x0, 683xx, and ColdFire! It was designed in the early 2000s to run on the xcopilot emulator, and although it was never completed, it paved the way for the next 20 years of embedded systems development for the original authors!
